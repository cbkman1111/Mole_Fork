+ 설명
ㄴ 정의한 스탯을 기반으로 할 수 있는 행동.

+ 패턴
ㄴ 스탯(감정) => 태도 => 행동.
ㄴ 우울감 -> 무기력 -> 잠만 잔다.
ㄴ 배고픔 -> 무기력 -> 음식 찾기.
ㄴ 공포심 -> 두려움 -> 숨기.
ㄴ 공포심 -> 패닉 -> 살인.




+ 스탯
ㄴ 힘
ㄴ 우울감
ㄴ 행복감
ㄴ 배고픔

+ 감정
ㄴ 수면
ㄴ 식욕
ㄴ 성욕
ㄴ 분노

+ 태도
ㄴ 행동으로 진행을 이어갈지 말지.

+ 찾기 행동
ㄴ 음식 찾기
ㄴ 분노 대상 찾기

+ 결과 행동
ㄴ 먹기
ㄴ 자기
ㄴ 구애
ㄴ 전투
ㄴ 패닉
ㄴ 놀기
ㄴ 공포

+ 행동으로 얻을 수 있는 스탯 효과
ㄴ 살인 : 공포심 하락
ㄴ 식사 : 배고픔 하락
ㄴ 놀이 : 외로움 하락
ㄴ 대화 : 우울증 하락
